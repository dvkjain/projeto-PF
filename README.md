# CRUD de Medicamentos

![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-green)

Sistema CRUD de medicamentos, feito utilizando **JavaScript**, **HTML** e **CSS**, que possibilita visualizar e editar uma tabela de registros de forma eficiente.

[![Deploy](https://img.shields.io/badge/Acessar_Sistema-64ffda?style=for-the-badge&logo=netlify&logoColor=00c7b7)](https://crud-medicamentos.netlify.app)

---

## 💡 Visão Geral e Objetivo

Este projeto foi desenvolvido com o foco em demonstrar a proficiência na criação de um sistema de gerenciamento de dados que implementa as quatro operações básicas (Create, Read, Update, Delete - CRUD) utilizando apenas tecnologias frontend (Vanilla JavaScript). O objetivo é fornecer uma interface de usuário funcional e intuitiva para o controle de um inventário simples de medicamentos.

## ⚙️ Funcionalidades (Features)

O sistema foi estruturado com diversas opções para garantir o gerenciamento completo da tabela:

* **CRUD Completo:** Suporte total às operações de gerenciamento de dados:
    * **Adicionar:** Insere um novo medicamento na tabela.
    * **Atualizar:** Edita os dados de um medicamento existente.
    * **Remover:** Exclui um registro da tabela.
* **Controle de Visualização:**
    * **Listar:** Exibe a tabela de medicamentos no estado atual.
    * **Iniciar:** Gera e carrega uma tabela inicial com dados de exemplo.
* **Busca e Filtragem Avançada:**
    * **Buscar:** Permite a busca por um medicamento específico na tabela.
    * **Filtrar:** Filtra os medicamentos exibidos por uma tarja específica (ex: Tarja Vermelha).
* **Manutenção:**
    * **Limpar:** Remove completamente todos os dados da tabela.
    * **Sair:** Fecha a interface ou sistema.

## 💻 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias web fundamentais:

* **HTML5:** Estrutura semântica e esqueleto da aplicação.
* **CSS3:** Estilização e design da interface.
* **JavaScript:** Lógica principal do sistema CRUD e manipulação dinâmica do DOM.
